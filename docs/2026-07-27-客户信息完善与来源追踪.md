# 客户信息完善与来源追踪

**日期：** 2026-07-27  
**状态：** 待实现

---

## 一、目标

1. 补全客户表单字段：个人客户加性别/生日/地址，企业客户加统一信用代码/行业/联系人
2. 新增 `registrationSource` 字段，记录数据是谁填写的

---

## 二、数据模型变更

### 新增枚举 `RegistrationSource`

```prisma
enum RegistrationSource {
  SELF     // 客户本人通过扫码落地页填写
  PARTNER  // 合伙人/员工在小程序录入
  ADMIN    // 管理员在后台录入
}
```

### Customer 表加字段

```prisma
registrationSource RegistrationSource @default(PARTNER)
```

---

## 三、接口变更

### `POST /customers`（已登录用户录入）

- currentUser.role === 'ADMIN' → `registrationSource = ADMIN`
- 其他 → `registrationSource = PARTNER`

### `POST /public/register`（客户扫码自助填写）

- `registrationSource = SELF`

## 四、小程序表单字段补全

### 个人客户（INDIVIDUAL）新增

| 字段 | 控件 | 必填 |
|------|------|------|
| gender | Picker（男/女/未知）| 否 |
| birthday | Picker（date）| 否 |
| address | Input | 否 |

### 企业客户（COMPANY）新增

| 字段 | 控件 | 必填 |
|------|------|------|
| creditCode | Input（统一信用代码）| 否 |
| industry | Input（行业）| 否 |
| contactName | Input（联系人姓名）| 否 |
| contactPhone | Input（联系人手机）| 否 |

### 详情展示

- 展示 `registrationSource`：自助填写 / 合伙人录入 / 管理员录入
