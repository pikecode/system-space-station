## 三、首次部署（已完成，仅供参考）

### 3.1 服务器初始化
```bash
# 安装 Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs

# 安装工具
npm install -g pnpm pm2

# 安装 PostgreSQL
apt-get install -y postgresql postgresql-contrib
systemctl enable postgresql && systemctl start postgresql
```

### 3.2 数据库创建
```bash
sudo -u postgres psql -c "CREATE USER appuser WITH PASSWORD 'Pp@123456';"
sudo -u postgres psql -c "CREATE DATABASE system_space_station OWNER appuser;"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE system_space_station TO appuser;"
```

### 3.3 代码上传与配置
```bash
# 本地打包（排除 node_modules、miniapp、web）
cd /path/to/system-space-station
tar --exclude='./node_modules' --exclude='./.git' \
    --exclude='./apps/miniapp' --exclude='./apps/web' \
    --exclude='./apps/api/dist' --exclude='./apps/api/node_modules' \
    -czf /tmp/system-space-station.tar.gz .

# 上传
scp -i ~/.ssh/id_ed25519_sss /tmp/system-space-station.tar.gz root@8.130.168.178:/opt/

# 服务器解压
ssh -i ~/.ssh/id_ed25519_sss root@8.130.168.178
mkdir -p /opt/app
tar -xzf /opt/system-space-station.tar.gz -C /opt/app
```

### 3.4 环境变量（服务器 `/opt/app/apps/api/.env`）
```env
DATABASE_URL="postgresql://appuser:Pp@123456@localhost:5432/system_space_station"
JWT_SECRET="<随机生成的字符串>"
PII_ENCRYPTION_KEY="<64位十六进制字符串>"
```

> ⚠️ JWT_SECRET 和 PII_ENCRYPTION_KEY 一旦生产使用不要修改，否则所有已登录 token 和加密数据失效。

### 3.5 安装依赖、迁移、启动
```bash
cd /opt/app
pnpm install --frozen-lockfile

cd apps/api
pnpm exec prisma generate
pnpm exec prisma migrate deploy
pnpm build

pm2 start dist/src/main.js --name "sss-api"
pm2 save
pm2 startup systemd -u root
```

### 3.6 Nginx 配置（自签名证书）
```bash
# 生成自签名证书
mkdir -p /etc/nginx/ssl
openssl req -x509 -nodes -days 3650 -newkey rsa:2048 \
  -keyout /etc/nginx/ssl/server.key \
  -out /etc/nginx/ssl/server.crt \
  -subj "/C=CN/ST=Shanghai/L=Shanghai/O=SSS/CN=8.130.168.178"

# 配置文件 /etc/nginx/sites-available/sss-api
```

```nginx
server {
    listen 80;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name _;

    ssl_certificate     /etc/nginx/ssl/server.crt;
    ssl_certificate_key /etc/nginx/ssl/server.key;
    ssl_protocols       TLSv1.2 TLSv1.3;

    location /api {
        proxy_pass         http://127.0.0.1:4100;
        proxy_http_version 1.1;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
    }
}
```

```bash
ln -sf /etc/nginx/sites-available/sss-api /etc/nginx/sites-enabled/sss-api
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

## 四、更新部署流程（日常使用）

每次代码更新后按以下步骤操作：

### 4.1 本地：提交代码并打包
```bash
# 确保代码已 commit
git status

# 打包（在项目根目录执行）
tar --exclude='./node_modules' --exclude='./.git' \
    --exclude='./apps/miniapp' --exclude='./apps/web' \
    --exclude='./apps/api/dist' --exclude='./apps/api/node_modules' \
    -czf /tmp/system-space-station.tar.gz .
```

### 4.2 上传到服务器
```bash
scp -i ~/.ssh/id_ed25519_sss /tmp/system-space-station.tar.gz root@8.130.168.178:/opt/
```

### 4.3 服务器上执行更新
```bash
ssh -i ~/.ssh/id_ed25519_sss root@8.130.168.178

# 备份旧版本（可选）
cp -r /opt/app /opt/app-backup-$(date +%Y%m%d)

# 解压新代码（保留 .env）
cp /opt/app/apps/api/.env /tmp/api.env.bak
rm -rf /opt/app
mkdir -p /opt/app
tar -xzf /opt/system-space-station.tar.gz -C /opt/app
cp /tmp/api.env.bak /opt/app/apps/api/.env

# 安装依赖
cd /opt/app && pnpm install --frozen-lockfile

# 运行数据库迁移（如有新 migration）
cd /opt/app/apps/api
pnpm exec prisma generate
pnpm exec prisma migrate deploy

# 重新编译
pnpm build

# 重启服务
pm2 restart sss-api

# 确认状态
pm2 list
```

### 4.4 重新编译小程序
如果改了小程序代码，在本地执行：
```bash
pnpm --filter miniapp build:weapp
```
然后用微信开发者工具上传 `apps/miniapp/dist/` 到微信平台。

## 八、注意事项

1. **微信小程序生产环境必须使用 HTTPS** — 当前使用自签名证书，正式上线需绑定域名 + 申请 SSL 证书（阿里云免费证书）
2. **`.env` 文件不纳入 git** — 服务器上的 `.env` 需手动维护
3. **数据库密码与服务器密码相同（Pp@123456）** — 上线前建议修改数据库密码并更新 `.env`
4. **PII_ENCRYPTION_KEY 不可修改** — 修改后历史加密数据（身份证等）无法解密
5. **阿里云安全组已开放端口**：22、80、443、4100
