## 三、首次部署（已完成，仅供参考）

### 3.1 服务器初始化
```bash
apt-get update
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs postgresql postgresql-contrib nginx
npm install -g pnpm pm2
systemctl enable postgresql nginx
systemctl start postgresql
```

### 3.2 数据库创建
```bash
sudo -u postgres psql -c "CREATE USER appuser WITH PASSWORD 'Pp@123456';"
sudo -u postgres psql -c "CREATE DATABASE system_space_station OWNER appuser;"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE system_space_station TO appuser;"
```

### 3.3 API 部署
```bash
# 本地打包（排除 node_modules、miniapp、web）
cd /path/to/system-space-station
tar --exclude='./node_modules' --exclude='./.git' \
    --exclude='./apps/miniapp' --exclude='./apps/web' \
    --exclude='./apps/api/dist' --exclude='./apps/api/node_modules' \
    -czf /tmp/system-space-station.tar.gz .

# 上传
scp -i ~/.ssh/id_ed25519_sss /tmp/system-space-station.tar.gz root@8.130.168.178:/opt/

# 服务器端
mkdir -p /opt/app
tar -xzf /opt/system-space-station.tar.gz -C /opt/app
cd /opt/app && pnpm install --frozen-lockfile
cd apps/api
pnpm exec prisma generate
pnpm exec prisma migrate deploy
pnpm build
pm2 start dist/src/main.js --name "sss-api"
pm2 save && pm2 startup systemd -u root
```


### 3.6 Nginx 配置
```bash
# 生成自签名 SSL 证书（10年有效）
mkdir -p /etc/nginx/ssl
openssl req -x509 -nodes -days 3650 -newkey rsa:2048 \
  -keyout /etc/nginx/ssl/server.key \
  -out /etc/nginx/ssl/server.crt \
  -subj "/C=CN/ST=Shanghai/L=Shanghai/O=SSS/CN=8.130.168.178"
```

配置文件 `/etc/nginx/sites-available/sss-api`：
```nginx
server {
    listen 80;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name _;

    ssl_certificate     /etc/nginx/ssl/server.crt;
    ssl_certificate_key /etc/nginx/ssl/server.key;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;

    # Web 管理后台（SPA）
    root /var/www/sss-admin;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api {
        proxy_pass         http://127.0.0.1:4100;
        proxy_http_version 1.1;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
    }
}
```

```bash
ln -sf /etc/nginx/sites-available/sss-api /etc/nginx/sites-enabled/sss-api
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

## 九、注意事项

1. **HTTPS 证书** — 当前使用自签名证书（10年有效）。正式上线需绑定域名并申请 CA 证书（阿里云免费证书），否则微信小程序生产版无法调用 API。

2. **`.env` 不进 git** — 服务器 `.env` 只存在于 `/opt/app/apps/api/.env`，更新代码时注意备份还原。

3. **JWT_SECRET / PII_ENCRYPTION_KEY 不可修改** — 修改后历史加密数据（身份证等）无法解密，所有用户需重新登录。

4. **数据库密码** — 当前与服务器密码相同（`Pp@123456`），正式上线前建议修改并更新 `.env`。

5. **微信小程序 API 域名** — 微信要求配置合法域名白名单，IP 直连仅限开发者工具（勾选"不校验域名"）调试。上线前在微信公众平台 → 开发 → 开发管理 → 服务器域名中添加 HTTPS 域名。

6. **数据库备份** — 目前无自动备份，建议定期执行：
   ```bash
   pg_dump -U appuser -d system_space_station > /opt/backup-$(date +%Y%m%d).sql
   ```
