# 小程序专业 CRM 视觉设计

## 目标

将现有小程序整理为安静、克制、信息优先的专业 CRM 工具。优化重点是高频扫描、表单录入、状态判断和关键操作反馈，不改变接口、权限与业务流程。

## 设计方向

- 以浅灰页面背景、白色内容面、墨绿色操作色构成基础视觉。
- 琥珀色仅表示待处理，绿色表示完成，红色表示失败或危险操作。
- 列表采用连续信息行，减少重复卡片和阴影，提升客户信息扫描效率。
- 详情采用身份摘要与分组信息面板，编辑采用分段表单和固定底部操作栏。
- 金额使用等宽数字和清晰字重，不使用夸张字号或大面积渐变。
- 动效仅覆盖按压、进入、加载和状态反馈，避免非必要装饰。

## 页面策略

1. 登录：建立产品识别，统一输入状态，增加表单内网络错误反馈。
2. 客户列表：固定搜索、新增入口、结果计数、紧凑客户信息行。
3. 客户详情：身份摘要、信息分组、统一编辑表单和底部操作栏。
4. 待办与分成：突出任务状态、金额和时间，弱化装饰性 Banner。
5. 会员流程：统一客户上下文、字段层级、审批状态和操作反馈。
6. 我的：紧凑个人摘要、分享码工具区、标准功能列表和海报弹层。
7. 邀请登记：与内部系统共用设计令牌，同时保留对外页面的友好感。

## 工程约束

- 使用 Taro 与微信原生组件，不新增 UI 组件库。
- 公共视觉规则集中在 `apps/miniapp/src/app.css`，页面只保留业务相关结构。
- 尽量清理重复内联样式，使用语义化 class 复用。
- 保持现有数据流、接口调用、鉴权和路由不变。
